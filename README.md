# YggLabs — Guide de leveling 1–175

Guia de evolução do YggIdle do nível 1 ao 175: escolha seu nível e veja onde upar, quais monstros aparecem juntos e quanto cada um entrega de EXP ajustada pela diferença de nível.

Site: https://ikugan132.github.io/ygglabs-leveling/

A rota cobre 1–175 conforme as faixas fornecidas pela comunidade em 2/11/2026, mantendo sobreposições, extensões e alternativas opcionais. Os detalhes dos mapas foram conferidos na wiki oficial do YggIdle. Agav / Echio cobre 118–124 (a wiki recomenda o Santuário para 124–128), até o Manuk 1 no 125. Adendos: Pirate Skeleton (Navio Fantasma, a partir do 39) e Hospital de Bangungot (ma_dun01, 100–116: muita EXP, quase nenhum loot).

É uma página estática (`index.html`), publicada pelo GitHub Pages a partir da branch `main`. Testes: `npm install` e `npm test`.
